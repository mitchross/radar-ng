# Android release builds (local, no cloud)

Builds run on this machine with Gradle. Google Play App Signing holds the app signing key; we sign uploads with an **upload key** that lives outside the repo.

## One-time setup

```bash
cd frontend
bash scripts/create-android-upload-key.sh
```

This creates `~/.radar-ng/android-upload.jks` and `~/.radar-ng/android-signing.env` (mode 600) and prints the upload certificate's SHA-256. Back both files up in a password manager. In Play Console, enroll the app in Play App Signing and use this upload key. If the upload key is ever lost, Play support can reset it.

## Build

```bash
cd frontend
bun run android:aab    # signed AAB for Play  -> artifacts/android/radarng-<version>-<versionCode>.aab
bun run android:apk    # signed APK to sideload -> artifacts/android/radarng-<version>-<versionCode>.apk
```

The script:
- runs `expo prebuild --platform android`, which regenerates `frontend/android`;
- loads the signing env;
- builds with a 4 GB Gradle heap;
- copies the output to `artifacts/android/` and prints the signer.

Without the env file it refuses to build unless `ALLOW_DEBUG_SIGNING=1` (QA builds only; Play rejects them).

How signing reaches Gradle: `plugins/withAndroidReleaseSigning.js` adds a `release` signing config that reads `RADAR_UPLOAD_*` Gradle properties. The script exports them as `ORG_GRADLE_PROJECT_RADAR_UPLOAD_*` environment variables, so no secret is written to the repo, `gradle.properties`, or the command line.

## Before each Play upload

- Bump `expo.android.versionCode` in `frontend/app.json` (and `expo.version` for user-visible releases).
- Build the AAB and upload it in Play Console.
- **Android developer verification** is required for any distribution, including sideloading: from 2026-09-30 in Brazil, Indonesia, Singapore and Thailand, and globally in 2027. Verify the developer account before sharing APKs.

## Repo layout for builds

`frontend/ios` and `frontend/android` are generated by prebuild and safe to delete. Everything a build produces (IPAs, xcarchives, AABs, APKs, Xcode Organizer exports) goes under `/artifacts/`, which git ignores.
