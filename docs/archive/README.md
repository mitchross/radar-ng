# Archive

Dated notes kept for history: QA passes, performance audits, review task lists, release notes for
past versions, and the Python → Rust migration plan and reviews. **Nothing here is maintained.**
Paths, commands and numbers may be out of date; the backend described in older files was Python.

For current docs, start at [../README.md](../README.md).
